# Archived B1 Pro ZMK Material

These files were moved intact during the V1 Max QMK migration. They document a
different keyboard, firmware, matrix, bootloader, and release process. Do not
build, flash, compare, or promote them as V1 Max artifacts.

The active V1 Max project starts without a custom-firmware baseline. Its source
and candidate records are described in the parent `V1-MAX/README.md`.
