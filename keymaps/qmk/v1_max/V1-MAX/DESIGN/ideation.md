# V1 Max Design Ideas

These are unapproved inputs for a V1-specific specification, not firmware
instructions.

- Preserve the stock four-layer Mac/Windows model before adding layers.
- Evaluate home-row modifiers using QMK Chordal Hold against normal typing.
- Put Tap Dance only on non-recovery keys and test each tap count explicitly.
- Keep DFU entry, the physical OS switch, wireless selection, and the encoder
  recoverable and visible in every test checklist.
- Decide whether Keychron Launcher/VIA remains part of the supported workflow
  before committing to fixed custom firmware.
