Keychron V1 Max QMK Map

This project has no approved custom map yet. This page deliberately does not portray a speculative layout as firmware truth.

The active target is ansi_encoder. Its keyboard.json defines the visual geometry.

The stock map has Mac Base/Fn and Windows Base/Fn layers, plus an encoder. A future generated view must read the reviewed keymaps/default/keymap.c rather than duplicate it by hand.
